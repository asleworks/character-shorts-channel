# 제작 중 겪은 문제

| 증상 | 해결 |
|---|---|
| Claude 채팅에 첨부한 그림이 Higgsfield 요청에서 참조되지 않는다. | Higgsfield에서 생성해 둔 그림의 job ID를 `medias[].value`에 넣는다. 사용자가 준 그림을 활용하려면 연결된 도구가 그 파일을 참조로 받을 수 있는지 먼저 확인한다. |
| 채팅에서 생성한 고화질 이미지가 장당 1.25크레딧이었다. | 세로 쇼츠는 기본 화질로 먼저 만든다. 실제 작업에서 기본 GPT Image 2.6은 장당 0.75크레딧이었다. |
| 한국어 대사를 일부 음성이 잘못 읽는다. | 숫자나 고유명사가 있는 짧은 실제 대사로 목소리 후보를 들어 본다. 사용자가 고른 목소리로 전체 대본을 읽힌다. |
| 인식된 단어가 빠지거나 실제 음성에 없는 말을 만들어 낸다. | 자막은 대본 원문을 쓰고 ASR은 타이밍에 쓴다. 보고서에 보간이 나오거나 컷이 어긋나면 음성을 다시 확인해 단어 타이밍 JSON을 고친 뒤 렌더한다. |
| 이미지 모델이 제목이나 소품의 숫자를 틀리게 그린다. | 글자 자리만 비워서 생성하고 `screen_text`로 제목, 숫자, 짧은 문구를 얹는다. |
| 투명 PNG에서 배경이 이상하게 보인다. | RGBA는 흰색 위에 합성한다. 렌더러는 테두리에 연결된 흰 여백을 정리한 뒤 그림을 배치한다. |
| 볼에 붉은 점이 생기거나 감정 표현이 장면마다 달라진다. | 강한 감정의 기준 그림을 Image 3에 넣고 `No red cheek blush.`를 문제 장면에 덧붙인다. |
| 배치 대기 중 타임아웃이 나거나 일부 장면만 실패한다. | 기존 job ID를 보존한 채 상태를 다시 조회한다. 실패가 확인된 장면만 골라 비용을 계산한 후 다시 요청한다. |
| 카드 문구가 너무 작거나 자막과 같은 내용을 반복한다. | `screen_text` 첫 줄을 짧은 제목으로 쓰고 설명은 두 줄 이내로 나눈다. 숫자 하나를 강조하려면 `number`에 적고 장면 시트로 확인한다. |
| 완성 파일이 3분을 넘긴다. | 렌더러가 붙이는 시작·끝 여백을 포함해 최종 MP4의 길이를 확인한다. 대사나 불필요한 무음을 줄이고 다시 렌더한 후 업로드 키트를 갱신한다. |
